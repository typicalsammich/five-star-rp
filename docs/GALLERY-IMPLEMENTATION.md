# The connection atlas

Six authentic project photos live in one desktop drafting world. A measured orthogonal route connects alternating risers with rounded elbows, couplings, branch collars and six mechanical controls. Cylindrical gradients run perpendicular to straight pipe segments; raised pipework progressively replaces the thin drawing through a scroll-controlled SVG mask. A short blue-white reflection marks water progression without continuous autoplay.

Native page scrolling tracks the camera between six compositions. Scene-specific masks reveal the real photographs as the camera reaches a connection. Filters rebuild geometry, branches, numbering, HUD and modal navigation from the same original project data. A single result has a shorter coherent route. Project navigation is immediate with a brief camera settle; normal scrolling is never intercepted.

Mobile has a separate measured, weaving route around normal-flow articles. It uses lighter reveals, 64px valve targets and no sticky camera. Reduced-motion preferences and the Browse without motion control provide a fully revealed presentation. Animation work is paused outside the gallery using IntersectionObserver; ResizeObserver, font readiness and image load events maintain measurements.

The project dialog expands from the selected image into a technical file. Native dialog focus containment, visible Close, Escape, previous/next and contact CTA are retained. Closing restores the same scroll position and focus with preventScroll. No project locations, specifications, before-and-after pairs or replacement photos were invented.

Core files: scripts/gallery-markup.mjs, public/gallery.js, public/gallery-geometry.js, public/gallery.css, data/project-image-sizes.json. The homepage uses a compact route preview rather than the full world.

Verification: 19 automated tests pass. Browser checks at 320, 375, 390, 430, 768, 1024 and 1440 pixels show six branches, one continuous route and no horizontal overflow. All six mobile valves open their corresponding projects. Desktop Water Heater detail navigation, Escape and exact position/focus return pass. All five categories and All Work rebuild the expected one-, two- or six-project networks. Browse without motion reveals all photos without masks. Geometry tests cover reverse progression and filtered layouts. A real OS reduced-motion preference was not emulated; its CSS and shared fallback logic were reviewed.
